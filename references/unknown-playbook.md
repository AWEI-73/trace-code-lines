# 未知：誠實交代，補查止於本題終點

不知道就不寫成知道；未知不是待辦清單。每筆交代類別、原因與目前最好的解釋，這是便宜且有界的工作。問題記在 question，另填：
- affects：會不會改變本題結論；`yes`＝會、`no`＝不會、`unsure`＝不確定。未填按不確定處理，並提示欄位未齊。
- class：只用 `not-run`、`model-choice`、`one-off`、`evidence-lost`、`owner-only`、`out-of-scope`。
- cause：一句話說明為何不知道，包含缺的資料、決定或證據。
- tried：影響或可能影響結論時，交代查過／跑過什麼、結果；沒試就寫沒試與原因。
- next：影響或可能影響結論時，填 `{action,cost}`；cost 用「免費讀取／隔離試跑／付費模型／Owner」，真帳號或授權決定歸 Owner。
- understanding：目前最佳解釋，明標推論並寫可推翻它的觀察；完全無線索就寫「沒有線索」。

## 執行次序

1. 先定終點：探索階段是本卡那一句問題；固定流程是成品與它宣告的驗收項目。碰到驗收項目的未知要補，或明寫限制後交付，不把缺證據說成驗收通過。
2. 判斷是否會改變本題結論。不會的只交代類別、原因與目前解釋，不標補做、不列提醒；值得之後追的只留一句「另一個問題」，不在本卡追，也不自動開卡。
3. 只為本題結論補查：會或不確定時，依下表先讀碼、設定及既有足跡，再做授權內必要的隔離試跑。不為把未知清到零擴張調查；不把「未查」稱為工具極限。
4. 做了仍未知，如實更新類別與試過內容，記具體卡點與目前解釋；不得換類別躲補查。付費、真帳號或 Owner 決定留待處理，不擴張授權；每個情境最多三次，無新假設不重跑，替身不當真實使用。
5. 「應先補做」只標：類別為沒去跑、成本為免費讀取或隔離試跑，且會或可能影響結論。缺類別或原因標「未交代原因」，缺是否影響標「欄位未齊」；開頭分列影響結論（含不確定及應先補做數）與僅記錄數。這些標示不改證據判定、不拒絕整卡。

## 對策表（僅用於會或可能改變本題結論的未知）

與本題終點無關的只記錄；以下方法不是每項未知都得走完的流程，前一步答不了且本題仍需要，才考慮提高成本。

| 原因／類別 | Agent 可執行的下一步 | 既有工具／產物 |
| --- | --- | --- |

| 走哪條路由模型決定／model-choice | 拆下面四題；不要把可接受集合或替身結果當模型選擇頻率 | stop-sites、宣告對照、water-source |
| 分支由設定或宣告決定／not-run | 用 version-chain 固定實際安裝版本；把具名宣告檔當輸入根，再依設定重算閉包 | [version-chain](runtime-tools.md)、[derive-map](runner.md) |
| 跨程序靠檔案交接／not-run | 找同一路徑或 schema 的寫入者與讀取者，核對內容與收據 | scripts/js-data-reads.mjs、scripts/value-receipts.mjs、[儀器](instrumentation.md) |

| 原始資料沒了／evidence-lost | 寫何時、為何遺失；不知就明說。列為限制，建議今後保留的原始內容、hash、時間與版本 | 報告；不虛構或重建成歷史證據 |

## 「模型決定」拆成四題

1. **程式接受哪些選擇？** 讀輸出 schema 和驗證函式，列有限集合與條件，每個答案附錨點。用體檢卡宣告對照核對提示與接受集合。
2. **每個選擇程式怎麼走？** 在隔離副本用替身逐一回放可接受選項，記走到哪、寫了什麼；依[水源與情境](water-sources.md)／[run-once](run-once.md)保存計畫與結果，標 AGENT_DRIVEN_STUBBED。失敗照記，不改預期湊 PASS。
3. **提示詞叫模型怎麼選？** 跑 `node scripts/stop-sites.mjs --prompts --root <repo> --out <file>`，必要時用 `--pattern` 縮小。讀候選的送出位置，過濾誤報，再與前兩題逐項對照「程式做得到但提示詞禁止／提示詞要求但程式不接受」。見[清冊限制](stop-sites.md)。
4. **模型實際選了什麼？** 先由 record-census 計歷史分布與搜尋範圍；有 Owner 付費授權才抽樣真模型，寫「n 次中 k 次」，不寫確定行為。沒有歷史且未授權抽樣，留下帶前三題答案的 model-choice。

前三題可用原碼和替身確定；如果資料不可讀或隔離試跑失敗，仍如實保留該題未知與具體原因，不因預期可查就宣稱已知。引用核對 PASS 不替代 agent 的語意覆核。
